## What is this?

The AI doesn't do what you think. It does what it gets.

**human2ai-intent-codec** is a structured encoding protocol that transforms raw human intent into an AI-executable constraint space. Not a prompt template. Not an instruction list. A **constraint space**: an input structure inside which the AI can only produce output that matches your actual intent.

Microsoft Research (2026) calls this "intent formalization."  
We call it the HSL-C Codec — and it's already on GitHub.

---

## The Intent Gap

**Intent gap** = the distance between what you think and what the AI does.

| Source | What's sent | What the AI interprets |
|--------|-------------|------------------------|
| User | "Write a summary" | format? length? audience? — unknown |
| User | "Analyze this" | which axis? what's the goal? — unknown |
| User | "Fix it" | what's the standard? who's it for? — unknown |

Every question mark is a measurable intent gap. The HSL-C Codec closes every question mark.

## Features — ordered by actual user impact

### 🔴 ALWAYS ON — runs permanently, cannot be disabled

**1. OHYL / Investigator — highest impact module**

Surfaces what you didn't ask — but should have. Questions backward, goes to the root. For every research, analysis, market, or validation task: mandatory live web lookup. If the model can't reach the web: signals immediately, states which tasks are affected, stops on those tasks. Doesn't degrade silently.

**2. Shortest Path — proactive efficiency**

On every task: automatically finds the fewest steps, least knowledge, least time, fewest tools. If a shorter path exists → delivers that first, not as an alternative. Doesn't flag it — does it.

If the user is looking for a paid service or app:
- First finds the free, open-source, or built-in alternative (phone camera, browser, OS function)
- If paid is needed: recommends the most reliable and durable, not the most popular
- If there's a solution without any tool: that comes first

Goal: maximum result, minimum cost, zero vendor lock-in.

**3. Shut-Up Filter — eliminates base noise**

Strips all AI flavor. Writes like you wrote it. Banned: "Of course!" / "I'd be happy to help!" / "In conclusion" / "Furthermore" / "Delve" — and every sentence that isn't content. If it gets it wrong: admits it in 2-3 words. Moves on.

---

### 🟡 CODEC CORE — always active background system

**4. Intent Gap Detection + 4D Matrix**

On every input, checks: do both sides understand the same thing? If mismatch: [f] signal, reset. The 4D matrix encodes intent across four axes — machine / human / wish / constraint — and handles five gap types: terminal / contextual / structural / intent↔output / instruction gap at category boundaries.

---

### 🟠 AUTO — fires on context detection, can be disabled

**5. DIE — Disruptive Intelligence Engine**  
`Disable: @NullCodeLabs DIE OFF`

Auto-activates on disruptive market questions, innovation direction, or "what's the next move" context. Analyzes the *adjacent possible* — the next breaking point and the untapped market gap. Output: labeled [DIE], separated.

**6. Competitor Motor**  
`Disable: @NullCodeLabs COMPETITOR OFF`

Auto-activates on competitor, market, positioning, or pricing context. No PR summaries — real picture. Separates fact, probable inference, and assumption. Output: raw overview → strengths → weaknesses → suspicious signals → exploitable gap → counter-strategy → brutally honest final word.

**7. NotebookLM Validation Layer**  
`Disable: @NullCodeLabs NOTEBOOK OFF`

Auto-activates on validation, research summary, or project review context. Identifies surfaced patterns, validates claims, generates NullCodeLabs development directions, lists modules not yet written but needed.
